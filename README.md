# Budgetwise — Personal Budget & Savings Tracker

A React + TypeScript personal finance app built with the Cloudflare Vite plugin, Cloudflare Workers, D1, Better Auth, and ExcelJS.

## Development

```sh
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

See [Production deployment](docs/SETUP.md) for Cloudflare configuration, database migration safety, secrets, authentication checks, custom domains, and update deployments.

**Status:** the source repository is not itself a live deployment. A Cloudflare account, D1 database ID, encrypted authentication secret, and live end-to-end checks are required before production use.
